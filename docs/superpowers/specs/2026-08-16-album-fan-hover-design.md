# 相册封面 hover 扇形展开动效（最左钉死版）

日期：2026-08-16
状态：已与用户确认方案（向右单侧展开 + 方案 A 几何反解）

## 目标

`src/pages/photos.astro` 相册封面的 hover 动效改为：

- **最左一张完全不动**（不平移、不旋转，hover 前后 transform 完全一致）。
- 其余图片沿"所有图片底边的公共切线圆"（铰链圆）**向右单侧展开**，相邻每张间隔 30°，5 张铺开 120°，像折扇从左侧轴心打开。
- 滑出顺序从**最右一张**开始，向左每张延迟 70ms（现有逻辑已满足，保留）。

## 现状问题

当前实现（commit 348eb31）里，展开后最左扇骨角度 θ₀ 取 `-((count-1)/2)*step`（5 张时为 -60°），而最左一张静止姿态的旋转角是 `t0*14`（-28°），两者不一致导致 hover 时最左一张仍会旋转 -28°→-60°，不满足"完全不动"。

## 设计（方案 A：几何反解）

只改 `fanFor()` 的角度选取，CSS 与 DOM 结构不动：

- θ₀ 改为最左一张的**静止倾角**：`theta0 = t0 * 14`（与静止姿态 `rot` 相同）。
- 铰链圆心 P 仍按现有公式反解（`px = x0 - arm·sinθ₀`、`py = y0 + arm·cosθ₀`，arm = hingeR + cardHalfH = 114px），使最左一张展开位 == 静止位。
- 其余卡片展开角 θᵢ = θ₀ + i×30°。5 张时为 -28°、2°、32°、62°、92°。
- 静止姿态、悬停延迟（`delay = (count-1-i)*70ms`，最右为 0）、过渡缓动、阴影、z-index 全部保持现状。
- 整体上浮（2026-08-16 追加，后改为同步）：hover 时容器 `.album-fan` 上浮 14px，与扇形展开**同时开始**（同 0.55s、同缓动）；卡片展开延迟保持 `var(--delay)`，移开时上浮与收拢同步复位。

## 已知表现（用户已知情）

- 展开后最右一张接近平躺（92°），会向右/向下溢出卡片区域，暂时遮住右侧邻居卡片和下方相册名；hover 时 `z-index: 30` 已抬高，移开即恢复。这是"每张 30° × 5 张"的必然结果。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
- 启动 dev 服务器在 `/photos/` 页面目检：hover 时最左一张纹丝不动，其余从最右开始依次沿圆弧向右展开成 120° 扇形；移开后收回。
